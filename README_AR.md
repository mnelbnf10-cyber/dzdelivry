# DzDelivery Pro
مشروع Flutter عربي RTL يتضمن تطبيقين مستقلين: تطبيق الزبون وتطبيق الإدارة/المحل.

## البناء عبر GitHub Actions فقط
1. أنشئ مستودعًا جديدًا في https://github.com/new.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، مع المجلد المخفي `.github`.
3. افتح Actions ثم `Build DzDelivery Pro APKs` ثم `Run workflow`.
4. بعد نجاح البناء، نزّل من Artifacts:
   - `DzDelivery-Customer-APK`
   - `DzDelivery-Admin-APK`
5. فك ضغط كل Artifact وثبّت `app-release.apk` على هاتف Android.

## حساب الإدارة التجريبي
البريد: `admin@dzdelivery.dz`
كلمة المرور: `123456`

## مهم
هذه نسخة Prototype: تسجيل الدخول والمنتجات والطلبات محلية وتجريبية ولا تتزامن بين الأجهزة. قبل الاستخدام التجاري يلزم Backend وقاعدة بيانات ومصادقة حقيقية وصلاحيات آمنة وإشعارات. لا تضع أسرارًا أو مفاتيح API في تطبيق الهاتف.

## إذا ظهر خطأ MyApp أو تحذيرات deprecated_member_use
استبدل ملفات المشروع القديمة بهذه النسخة كاملة، ولا ترفع الملفات فوق النسخة القديمة دون حذف الملفات القديمة أولًا؛ خصوصًا `test/widget_test.dart`. الاختبارات في هذه النسخة تستورد عنصر التطبيق الصحيح لكل تطبيق، واستُبدل `withOpacity` بـ `withValues(alpha: ...)`.
